# Passenger-counter-app
<h4>This is a Passenger Counter App . It helps staff count passengers entering the platform and save the total number</h4>
<br>
<h2>Key Features</h2>
<list>
  <ul>
    Increase Button- Adds 1 to the count when a passengers enters.
  </ul>
  <ul>
    Save Button- Saves the total passenger count for the current train.
  </ul>
</list>
<br>
<h2>Tech Stack</h2>
<list>
  <ul>
    HTML- Creates the layout and buttons.
  </ul>
  <ul>
    CSS- Makes the app look clean and neat.
  </ul>
  <ul>
    JavaScript- Makes the counting and saving buttons work
  </ul>
</list>
